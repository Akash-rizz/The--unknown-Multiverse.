# THE UNKNOWN — 3D ULTIMATE

A single-page, static, GitHub-Pages-ready 3D science observatory.

## What is inside
- Real Three.js/WebGL 2 rendering
- Interactive Solar System with spherical planets
- Planet rotation + orbital revolution
- Earth + Moon + artificial satellite
- 3D asteroid belt + star field
- Stylized 3D black-hole visualization
- 3D DNA-inspired helix
- Quantum conceptual core
- 3D neural-network-inspired AI core
- Orbit / zoom / pan controls
- Click/tap object inspection
- Bloom post-processing
- Mobile performance mode
- No build step

## Important scientific note
The Solar System uses deliberately compressed distances/sizes so a human can explore it in one interactive scene. The black hole, quantum, DNA and AI sections are educational visual models, not research-grade simulations.

## Deploy on GitHub Pages
1. Create a new public GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch → main → / (root)**.
5. Save and open the generated GitHub Pages URL.

The project loads Three.js and its addons from jsDelivr, so an internet connection is needed for the 3D library.
